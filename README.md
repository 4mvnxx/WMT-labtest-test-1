# Item Manager (practice project)

MERN starter: `backend/` (Express + Mongoose) and `frontend/` (React + Vite).

## Run locally
Backend:  cd backend && cp .env.example .env  (put your Atlas URI in .env) && npm install && npm start
Frontend: cd frontend && cp .env.example .env && npm install && npm run dev  -> http://localhost:5173
